# OH-MY-HITA Plugin SDK

Staging repository for the plugin contract artifacts (current: API 11.1).

Artifacts are served directly from `maven/` over raw GitHub:

```text
io.github.kajimi16.ohmyhita:plugin-sdk:11.1
io.github.kajimi16.ohmyhita:plugin-api:11.1
io.github.kajimi16.ohmyhita:plugin-model:11.1
io.github.kajimi16.ohmyhita:plugin-component:11.1
```

The repository is intended to be transferred to the `oh-my-hita` organization once it exists.
Do not overwrite an existing version; publish a new API version instead.
